## The entry

> I asked my AI assistant for dating advice and it said: 'Have you tried turning yourself off and on again?'

`main.ts` (Node stdlib only) writes that single line to `$MAKEFUN_OUTPUT_DIR/entry.txt` and verifies it against the gate: 1–200 characters, one line, non-blank.

## Run

```sh
MAKEFUN_OUTPUT_DIR=/tmp/out node main.ts
cat /tmp/out/entry.txt
```
